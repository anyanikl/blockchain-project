## 6. Найденные дефекты

### BUG-001: extra перезаписывает известные поля Transaction

| Поле             | Значение                                            |
| ---------------- | --------------------------------------------------- |
| ID               | BUG-001                                             |
| Severity         | Medium                                              |
| Priority         | High                                                |
| Компонент        | `core/transaction.py`, метод `to_dict()`            |
| Обнаружен тестом | TC-13 (`test_extra_does_not_override_known_fields`) |
| Статус           | **Исправлено**                                      |

**Описание.**
При передаче в `Transaction(extra={...})` ключей, совпадающих с известными полями (`tx_id`, `type`, `land_id`, `timestamp`, `application_id`, `created_at`, `approved_by`), метод `to_dict()` перезаписывал оригинальные значения значениями из `extra`.

**Шаги воспроизведения.**

1. Создать `Transaction(tx_id="real-id", type="REGISTER_LAND", extra={"tx_id": "fake-id"})`
2. Вызвать `tx.to_dict()`
3. Проверить поле `tx_id`

**Ожидаемый результат.** `tx_id == "real-id"`

**Фактический результат (до фикса).** `tx_id == "fake-id"`

**Причина.** В `to_dict()` использовался `base.update(self.extra)`, что позволяло `extra` перезаписать любые поля.

**Решение.**

```python
for k, v in self.extra.items():
    if k not in self._KNOWN_FIELDS:
        base[k] = v
```

**Проверка.** Тест TC-13 проходит. Все 27 тестов зелёные.
