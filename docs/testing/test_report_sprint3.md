## 4. Негативные тесты

Проверяют, что система **правильно обнаруживает ошибки** и **не падает**.

### 4.1. Подмена данных блока (пункт a)

| ID    | Тест                       | Что проверяет                                    | Ожидаемый результат                                 | Полученный    | Статус |
| ----- | -------------------------- | ------------------------------------------------ | --------------------------------------------------- | ------------- | ------ |
| NT-01 | `test_block_hash_mismatch` | Изменение `owner` внутри блока → хэш не сходится | `is_valid() == False`, ошибка `BLOCK_HASH_MISMATCH` | Соответствует | PASS   |

**Шаги:**

1. Создана транзакция, замайнен блок.
2. В блоке изменено `transactions[0]["owner"] = "Hacker"`.
3. Вызван `is_valid()`.
4. Получен отчёт с ошибкой `BLOCK_HASH_MISMATCH`.

### 4.2. Разрыв связи блоков (пункт b)

| ID    | Тест                      | Что проверяет                   | Ожидаемый результат                                | Полученный    | Статус |
| ----- | ------------------------- | ------------------------------- | -------------------------------------------------- | ------------- | ------ |
| NT-02 | `test_prev_hash_mismatch` | Подмена `previous_hash` блока 2 | `is_valid() == False`, ошибка `PREV_HASH_MISMATCH` | Соответствует | PASS   |

**Шаги:**

1. Создана цепочка из 3 блоков.
2. У блока 2 изменён `previous_hash = "f" * 64`.
3. Вызван `is_valid()`.
4. Получен отчёт с ошибкой `PREV_HASH_MISMATCH`.

### 4.3. Подмена хэша транзакции (пункт c)

| ID    | Тест                      | Что проверяет                               | Ожидаемый результат                              | Полученный    | Статус |
| ----- | ------------------------- | ------------------------------------------- | ------------------------------------------------ | ------------- | ------ |
| NT-03 | `test_tx_hash_mismatch`   | Изменение `land_id` + подмена `tx_hash`     | `is_valid() == False`, ошибка `TX_HASH_MISMATCH` | Соответствует | PASS   |
| NT-04 | `test_tx_error_has_index` | Ошибка указывает `block_index` и `tx_index` | `block_index == 1`, `tx_index == 1`              | Соответствует | PASS   |

**Шаги NT-03:**

1. Создана транзакция, замайнен блок.
2. В транзакции изменён `land_id = "hacked"` и подменён `tx_hash`.
3. Вызван `is_valid()`.
4. Получен отчёт с ошибкой `TX_HASH_MISMATCH`.

**Шаги NT-04:**

1. Создано 3 транзакции в одном блоке.
2. Подменена вторая транзакция (`transactions[1]`).
3. Вызван `is_valid()`.
4. Ошибка содержит `block_index == 1` и `tx_index == 1`.
